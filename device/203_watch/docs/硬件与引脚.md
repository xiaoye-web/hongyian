# 硬件与引脚

两块板：**WEAR**（手表扩展板，屏和传感器都焊在它上面）和 **EXB**（底板，WS63 核心板 + 各种座子）。
依据是两份原理图：`HTXH_XS_WEAR_SCH V0`、`HTXH_XS_EXB_SCH V1`，第 1 页，同时核对可视线路与导出的网络标签。

> 约定：下文 `IO7` 这类名称是**原理图网络名**，对应 SDK 里的 GPIO 编号 7。

## 一、屏的 7 个脚（WEAR 板 `LCD1` 座）

座子型号 `KH-2.54FH-1X7P-H8.5`，屏模组 1:1 直插，7 针全占满。

| LCD1 脚 | 网络 | 说明 |
| --- | --- | --- |
| 1 | VCC | 5V0 |
| 2 | GND | |
| 3 | `SPI0CK` | 时钟 |
| 4 | `SPI0MOSI` | 数据 |
| 5 | `DC` | 命令/数据 |
| 6 | `SPI0CS` | 片选 |
| 7 | `RST` | 复位 |

模组背面丝印 `RST CS DC DA CL GD VC`，与座子顺序逐位一致，**不存在插反或镜像**。

## 二、圆屏完整线路（LCD1 → WEAR → EXB → 网络）

| LCD1 | WEAR | EXB | 网络 |
| --- | --- | --- | --- |
| 1 VCC | J1-12 | J3 / J4-12 | 5V0 |
| 2 GND | J1-10 | J3 / J4-10 | GND |
| 3 SCL | **J2-8** | J1 / J2-9 | **IO7** |
| 4 SDA | J1-9 | J3 / J4-9 | IO9 |
| 5 DC | J1-8 | J3 / J4-8 | IO10 |
| 6 CS | J1-7 | J3 / J4-7 | IO11 |
| 7 RST | J1-6 | J3 / J4-6 | IO12 |

WEAR `J1` 的 12 针与 EXB `J3`/`J4` **同号对接**。

5 根信号里 4 根走 `J1`（12 针），只有时钟走 `J2`（10 针）——它是唯一一根必须靠 `J2` 才能到 MCU 的信号。

## 三、WEAR 板两排针的网表

```
NLSPI0CK   = { PIJ208, PILCD103 }   J2-8  → LCD1-3
NLSPI0MOSI = { PIJ109, PILCD104 }   J1-9  → LCD1-4
NLDC       = { PIJ108, PILCD105 }   J1-8  → LCD1-5
NLSPI0CS   = { PIJ107, PILCD106 }   J1-7  → LCD1-6
NLRST      = { PIJ106, PILCD107 }   J1-6  → LCD1-7
```

**注意一处网表读法的坑**：导出的文本里 `NLRST` 那一行后面紧跟着 `PIJ204`，很容易被读成
「RST 也接了 J2-4」。实际上 `PIJ204` 属于下一个网络：

```
NLSensor0INT = { PIJ204, PIU208 }   J2-4  → MPU6050 的 INT
```

`J2-4` 是 MPU6050 的 `Sensor_INT`，**不是** LCD 的 RST；LCD 的 RST 只有 `J1-6` 一个来源。

## 四、EXB 板的四排针

EXB 上 `J1` 与 `J2` 是同一组网络（并排引出），`J3` 与 `J4` 同理。

| 脚 | J1 / J2 | 脚 | J3 / J4 |
| --- | --- | --- | --- |
| 1 | GND | 1 | I2C SCL |
| 2 | IO0 | 2 | I2C SDA |
| 3 | IO1 / UART0_RXD | 3 | IO14 |
| 4 | RESET | 4 | IO3 |
| 5 | IO2 / UART0_TXD | 5 | IO13 |
| 6 | IO4 | 6 | **IO12 = RST** |
| 7 | IO5 | 7 | **IO11 = CS** |
| 8 | **IO6** | 8 | **IO10 = DC** |
| 9 | **IO7**（另引到 J7-1） | 9 | **IO9 = MOSI**（另引到 J8-1） |
| 10 | IO8 | 10 | GND |
| 11 | 3V3 | 11 | 3V3 |
| 12 | — | 12 | 5V0 |

另有三个单针测试点：`J6-1 = IO3`、`J7-1 = IO7`、`J8-1 = IO9`。

## 五、WEAR J2 与 EXB J1/J2 的对应

`J2` 是 10 针，落在 EXB 左侧连接器的**第 2..11 针**，不是第 1 针对第 1 针。
原理图里 `J2` 的符号多画了圆点，**不能按图形圆点数针**，要按有效针号 1..10 算。

| WEAR J2 | 功能 | EXB 对应针 | EXB 网络 |
| --- | --- | --- | --- |
| 1 | V_ADC | 2 | IO0 |
| 2 | NC | 3 | IO1 |
| 3 | NC | 4 | RESET |
| 4 | Sensor_INT（MPU6050） | 5 | IO2 |
| 5 | AUX_DA | 6 | IO4 |
| 6 | AUX_CL | 7 | IO5 |
| 7 | ADO（MPU6050 地址脚） | 8 | IO6 |
| 8 | **SPI_CK** | 9 | **IO7** |
| 9 | NC | 10 | IO8 |
| 10 | 3V3 | 11 | 3V3 |

## 六、时钟就是 IO7，代码里的五个脚全部正确

两条独立证据同时成立，而且互相印证：

1. **`J2-7` = ADO（MPU6050 的地址脚）→ EXB 第 8 针 = IO6。**
   实测 IO6 被外部死死拉低（内部上拉读到 0、下拉也读到 0）。MPU6050 在 `WHO_AM_I`
   上回的是 `0x68`，说明 ADO 确实是低电平——两者完全吻合。
   这一条同时证明：**J2 已经插好，且对齐正确。**
2. **`J2-8` = SPI_CK → EXB 第 9 针 = IO7。** 既然 J2-7 落在 IO6，J2-8 就必然落在 IO7。

所以：

- 不需要假设「错 2 针」，也不需要把时钟改成 IO8；
- `LCD_SCL=IO7 / SDA=IO9 / DC=IO10 / CS=IO11 / RST=IO12` 与原理图一致，**代码的引脚定义没有问题**。

> 早先的版本曾经推断「时钟可能落在 IO8」，那是把 `ADO` 当成 `J2-6` 算错了位置。
> `J2-6` 是 `AUX_CL`，`ADO` 在 `J2-7`。修正后矛盾消失。

## 七、供电

- `LCD1-1` → WEAR `J1-12` → EXB `J3/J4-12` = **5V0**；`LCD1-2` → `J1-10` → `J3/J4-10` = GND。
- 模组背面能看到 `U3`（三脚封装）+ `C3~C7`，形态像 5 V→3.3 V 的 LDO，但**没有实测**。
  背光亮只能证明 VCC/GND 两个焊点是通的（背光 LED 不经过屏的控制器），
  既不能证明供电电压正常，也不能证明另外 5 根信号线通。要用万用表量 U3 输出才能定论。

## 八、还没验证的部分

以上都是**原理图层面**的对应关系，不代表实物通断已经测过。仍需实测：

- `LCD1-3` 到 EXB `J7-1`（IO7 测试点）的蜂鸣档通断；
- `U3` 输出电压是否 3.3 V；
- `SCL`/`SDA` 上是否有波形。

实测数据与逐版排查过程见 [`点亮排查记录.md`](点亮排查记录.md)。
